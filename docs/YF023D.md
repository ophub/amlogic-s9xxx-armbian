# YF-023D (RK3568) Armbian 定制固件构建说明

> 由 ophub 构建体系自动集成，分支 yf023d。

本分支为 **YoungFeel YF-023D v6**（RK3568，板载联芸 Maxio **MAE0621A** 千兆以太网 PHY）添加了 ophub 式 Armbian 一键编译支持。

## 本分支新增内容

| 文件/目录 | 作用 |
|---|---|
| `build-armbian/armbian-files/common-files/etc/model_database.conf` | 新增板卡行 `r220 / yf023d`（FDTFILE=rk3568-yf-023d-v6.dtb，KERNEL_TAGS=stable/6.12.y_6.18.y） |
| `build-armbian/u-boot/rockchip/yf023d/` | 公版 u-boot（取自 rock-3c：idbloader.img + u-boot.itb，已实测可在 YF-023D 启动） |
| `compile-kernel/tools/patch/linux-6.12.y/001-*` | Maxio MAE0621A PHY 驱动补丁（6.12 内核树内无此驱动） |
| `compile-kernel/tools/patch/linux-6.12.y/002-*` | 板卡设备树 `rk3568-yf-023d-v6.dts` 补丁（源自原厂固件提取并改写为主线风格） |
| `compile-kernel/tools/patch/linux-6.18.y/001-*` | 同上 DTS 补丁（6.18 树内已自带 maxio 驱动，无需重复打） |
| `yf023d/kernel-config/config-6.12` | 6.12 内核配置（在上游 stable 配置基础上追加 `CONFIG_MAXIO_PHY=y`） |
| `yf023d/kernel-config/config-6.18` | 6.18 内核配置（上游原版，已含 `CONFIG_MAXIO_PHY=y`） |
| `.github/workflows/compile-yf023d-kernel.yml` | 编译定制内核 → 发布到本仓库 `kernel_stable` Release |
| `.github/workflows/build-yf023d-image.yml` | 基于上游底包重打包出 YF-023D 完整固件 → 发布到 Release |

## 构建步骤

1. **先编内核**（首次必做）：Actions → *Compile YF-023D kernel* → Run workflow
   - `kernel_version` 选 `6.12.y_6.18.y` 可同时编两个版本；默认 `6.12.y`
   - 成功后内核包出现在仓库 Releases 的 `kernel_stable` 标签下
2. **再打固件**：Actions → *Build YF-023D Armbian image* → Run workflow
   - `set_release` 默认 `bookworm`；`armbian_kernel` 默认 `6.12.y`
   - 成功后在 Releases 下载 `Armbian_*_arm64_yf023d_*` 固件

## 刷机

- **TF 卡启动**：用 Rufus/balenaEtcher 把 `.img` 写入 TF 卡，插卡开机。
- **写入 eMMC**：TF 卡系统启动后执行 `armbian-install`，在设备列表中选择 **YF-023D（ID 220）**。
- **线刷**（进 MaskROM/Loader）：可用 RKDevTool 配合 rock-3c 的 MiniLoaderAll 烧写固件 img。
- 默认登录：`root / 1234`。串口调试：UART2，1500000 波特率。

## 验证网口

```bash
dmesg | grep -iE "maxio|mae0621|eth"
# 预期看到: MAE0621A READY / eth0: Link is Up - 1Gbps/Full
ip addr show eth0   # DHCP 获取 IP
```

## 后续升级内核

改完代码或想换新版本时：重新跑 *Compile YF-023D kernel*，设备上执行 `armbian-update` 按提示安装新内核即可。

## 备注

- 6.18.y 与 6.12.y 内核均可用于本板；两者都包含 MAE0621A 驱动与定制 DTB。
- 若上游 unifreq/ophub 内核树大幅变动导致补丁失效应失败（构建日志会提示 `Failed to apply the patch, skipping`），需按新源码树重新生成补丁。
